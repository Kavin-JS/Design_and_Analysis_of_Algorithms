Classroom presence

Two ESP32 nodes listen for the registered BLE devices. Attendance is decided by presence across the whole class, so a student who leaves partway through is marked absent.

End the class and save attendance?

Each student is marked present or absent from how long they stayed in range. Press this while students are still in the room, because anyone already out of range for too long is marked absent.

Discard this class?

The current class is thrown away without saving and a new one starts now. Rows already saved in the CSV are kept. Use this for test runs.
